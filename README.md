# Hello World REST API (Spring Boot)

A simple Spring Boot project demonstrating a REST API.

## Features
- REST endpoint `/Student/hello` returns a "Hello World" message.
- Built with `@RestController` and `@RequestMapping`.
- Bootstrapped using `@SpringBootApplication`.

## How to Run
1. Clone the repo.
2. Run the application:
   ```bash
   mvn spring-boot:run
